# ADR-0001 · Registrar decisões de arquitetura em ADR

- **Status:** proposto
- **Data:** 2026-11-06

## Contexto
O projeto tem várias decisões estruturais (linguagens, PACS, infraestrutura) que precisam ser rastreáveis.

## Decisão
Toda decisão estrutural é registrada como ADR curto (contexto, decisão, consequências), numerado e imutável; mudanças viram um novo ADR que substitui o anterior.

## Consequências
Histórico claro para quem entrar no projeto; revisão de decisões fica explícita.
